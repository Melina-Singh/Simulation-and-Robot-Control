## About The Project

KhetiBot is a robotics project aimed at exploring autonomous pesticide spraying for small-scale farms in Nepal. The project uses Blender for 3D modeling and Gazebo Classic for physics-based simulation to develop a virtual representation of the Panchkhal Campus environment and a four-wheeled differential-drive spraying robot. By integrating YOLOv8n for vision-based object detection with ROS 2, the system can identify tomato plants and trigger a virtual spraying mechanism for three seconds upon detection. Initially, a physical prototype was developed using a Raspberry Pi 5 and other hardware components. However, due to hardware power-delivery limitations, development shifted toward a simulation-based approach. The resulting system demonstrates robot movement, plant detection, and virtual spraying functionality within the simulated environment. Although the project establishes a foundation for precision-agriculture applications, autonomous navigation and real-world agricultural field testing remain areas for future development.
